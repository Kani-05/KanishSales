# Kanish Sales – Online Shopping App

A front-end e-commerce demo with a product catalog, filters, cart, and wishlist. It shows how a shopping experience can be built as a single HTML file, with prices in Indian rupees (₹).

**Live demo:** https://kani-05.github.io/KanishSales/

<!-- Add a screenshot: ![Kanish Sales storefront](screenshot.png) -->

## Features
- **Browse and search:** product search plus categories (Electronics, Fashion, Home & Appliances, Footwear).
- **Filters and sorting:** max-price slider, rating filter, express-delivery filter, and sorting by popularity, price (low to high or high to low), rating, and biggest discount.
- **Product details:** pop-up with images, specs, rating, reviews, and discount.
- **Cart and wishlist:** add to cart, save to wishlist, cart drawer, and a checkout step.
- **Order tracking** and toast notifications.
- **LLM token-savings dashboard:** an illustrative panel showing how token usage could be optimized in an AI-powered shop. (Display only; the app makes no live AI calls.)

## Built with
HTML, Tailwind CSS, and vanilla JavaScript in a single file. Product photos are loaded from Unsplash. Built with Google Antigravity (AI-assisted development).

## Run locally
Download `index.html` and open it in a browser. An internet connection is needed for the product images and Tailwind.

## Note
This is a demo front-end. The product data is sample data, and there is no real payment or backend.
